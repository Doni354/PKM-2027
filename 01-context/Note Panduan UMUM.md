**# 📑 Catatan Panduan Umum PKM**



**## 🎯 Kriteria**

**- Menumbuhkan kepekaan mahasiswa terhadap problematika faktual di masyarakat/dunia usaha.**

**- Mengasah kreativitas menghasilkan karya \*\*fungsional inovatif solutif berbasis iptek\*\*.**

**- \*\*Luaran utama\*\*: produk skala penuh (1:1), bukan prototipe.**



**## 🔍 Inti Kegiatan**

**- Karya berupa produk fungsional inovatif solutif skala penuh.**

**- Berbasis iptek, siap diproduksi massal.**



**## 📌 Luaran Wajib**

**1. Laporan Kemajuan**  

**2. Laporan Akhir**  

**3. Produk Fungsional Skala Penuh + Dokumen Teknis**  

**4. Akun Media Sosial**  



**## 📱 Catatan PKM Sosmed**

**- Buat akun sosmed khusus topik PKM.**  

**- Pilih min. 1: IG / TikTok / Twitter-X / FB / YouTube.**  

**- Konten edukasi (video, gambar, dll).**  

**- Wajib ada posting ber-ads (max Rp500.000, jadwal serentak).**  

**- Disarankan posting reguler (harian/mingguan).**  



**## 📚 Tema Serupa**

**\*\*Penguatan Pendidikan, Sains, dan Teknologi\*\***  

**- Fokus pada peningkatan kualitas SDM \& daya saing bangsa.**  

**- Mahasiswa ditantang menghasilkan ide kreatif untuk solusi masalah pendidikan, sains, teknologi.**

**## 📊 Uji Similaritas**

**- Proposal wajib uji similarity (Turnitin/iThenticate/dll).**  

**- Indeks similarity max \*\*25%\*\*.**  

**- Lampirkan hasil uji (pendahuluan–daftar pustaka).**  



**## 📝 Penilaian Proposal**

**### Tahap 1 – Seleksi Administrasi**

**- Persyaratan wajib: tanggal, tanda tangan, biodata, nomor halaman, surat pernyataan, nama sesuai PDDikti, dll.**  

**- Format sesuai Panduan PKM.**  

**- Program sesuai bidang PKM.**  

**- Judul sesuai tema.**  

**⚠️ Jika ada 1 tidak sesuai → gugur.**



**### Tahap 2 – Seleksi Substansi**

**- Fokus: kreativitas, kekinian topik, tantangan intelektual.**  

**- Dinilai oleh 2 penilai (nilai akhir = jumlah keduanya).**  

**- Pendanaan sesuai nilai bidang PKM + dana tersedia.**  

**- Hasil diumumkan di \*\*simbelmawa/pkm\*\*.**  



**## 📈 Penilaian PKM-KI**

**- Aspek penilaian:**

&#x20; **1. Mutu proposal (NP).**  

&#x20; **2. Nilai Laporan Kemajuan (NLK).**  

&#x20; **3. Mutu hasil pelaksanaan PKM (NM).**  



**- Rumus Nilai Akhir:**  

&#x20; **\*\*NA = 0,3 × NP + 0,2 × NLK + 0,5 × NM\*\***  

&#x20; **- NA = Nilai Akhir**  

&#x20; **- NP = Nilai Proposal**  

&#x20; **- NLK = Nilai Laporan Kemajuan**  

&#x20; **- NM = Nilai PKP2 (10% Dokumen Teknis Produk + 40% Presentasi)**
